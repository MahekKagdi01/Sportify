#  Sportify

### A Sports-Focused Web Platform

Sportify is a web-based platform designed to provide users with an interactive experience for exploring sports, managing sports-related activities, and engaging with sports events.

The project provides a user-friendly interface with authentication, event participation, playground information, and sports-related content.

## Features

- User Registration & Login
- User Authentication
- Explore Playgrounds
- Apply for Sports Events
- Sports Activity Management
- Playground Listing
- Responsive Web Interface
- Interactive and User-Friendly UI

## Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactive functionality
- **PHP** – Backend development
- **MySQL** – Database management
- **CSV** – Playground/event-related data storage
